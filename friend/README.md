# 가족 대시보드 (빈 복사본)

가족 일정 시계, 오늘의 과제, 살림, 달력, 서로에게 할 말 등을 한 화면에서 쓰는 웹앱이에요.
데이터는 **우리 집 Firebase(무료)** 에만 저장돼요. 다른 집과 섞이지 않아요.

주소: https://s32120255-debug.github.io/family-dashboard/friend/

## 처음 설정 (한 번만, 15분쯤)

컴퓨터에서 하는 게 편해요. 구글 계정 하나로 해요.

1. **Firebase 프로젝트 만들기**
   https://console.firebase.google.com 접속 → 「프로젝트 만들기」 → 이름 아무거나(예: myhome) → Google 애널리틱스는 꺼도 돼요 → 만들기.

2. **구글 로그인 켜기**
   왼쪽 「빌드 → Authentication」 → 「시작하기」 → 「Google」 → 「사용 설정」 켜기 → 지원 이메일 고르기 → 저장.

3. **대시보드 주소 허용하기**
   같은 Authentication 화면 위쪽 「설정」 탭 → 「승인된 도메인」 → 「도메인 추가」 → `s32120255-debug.github.io` 입력 → 추가.

4. **저장소(Firestore) 만들기**
   왼쪽 「빌드 → Firestore Database」 → 「데이터베이스 만들기」 → 위치 `asia-northeast3 (Seoul)` → 「프로덕션 모드」 → 만들기.

5. **우리 가족만 들어오게 규칙 넣기**
   Firestore 화면 위쪽 「규칙」 탭 → 안에 있는 글을 전부 지우고, 이 폴더의 `firestore.rules` 내용을 붙여 넣어요.
   `family1@gmail.com`, `family2@gmail.com` 자리에 **가족 구글 메일**을 적어요(사람 수만큼 줄 추가, 소문자로). → 「게시」.

6. **웹 설정 복사하기**
   왼쪽 위 톱니바퀴 → 「프로젝트 설정」 → 아래 「내 앱」에서 `</>`(웹) 아이콘 → 앱 이름 아무거나 → 「앱 등록」.
   화면에 나오는 `const firebaseConfig = { ... };` 부분을 통째로 복사해요.

7. **대시보드 열기**
   위 주소를 Chrome으로 열기 → 복사한 설정을 붙여 넣고 「저장하고 시작하기」 → 「구글로 로그인」.
   처음 들어가면 **화면 이름, 가족 부르는 이름, 아이 이름**을 물어봐요. 적으면 끝!

## 다른 기기(태블릿·가족 폰)에서 쓰기

「관리자」 → 「다른 기기용 링크 복사」 → 그 링크를 카톡 등으로 보내서 **Chrome에서** 열어요.
그 기기에서는 설정 붙여 넣기 없이 바로 로그인 화면이 나와요. (규칙에 메일을 적은 계정만 들어와요)

## 자주 막히는 곳

- 「승인된 도메인에 이 주소가 없어요」 → 3번을 다시 확인.
- 「구글 로그인이 꺼져 있어요」 → 2번을 다시 확인.
- 「이 계정은 아직 허용되지 않았어요」 → 5번 규칙에 그 메일이 있는지, 「게시」를 눌렀는지 확인.
- 카톡 안에서 열면 로그인이 막혀요 → 「다른 브라우저로 열기」로 Chrome에서 열기.

## 바꿀 수 있는 것

- 관리자 모드(오른쪽 위 「관리자」): 아이 일정·과제 넣기, 가족 이름 바꾸기, 관리자 비밀번호 정하기.
- 나머지 칸(달력, 식단, 장보기, 살림 등)은 누구나 추가·수정할 수 있어요.
